# Weather Fetching App

A simple web application that lets users get the current weather for any city in the world. Built with HTML, CSS, and JavaScript, using the OpenWeatherMap API.

---

## Features

- Search weather by city name  
- Display current temperature, weather conditions, humidity, and wind speed  
- Responsive design for desktop and mobile  
- Handles invalid city names with proper error messages

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/weather-app.git
```
2. Navigate into the project folder:
```bash
cd weather-app
```
3. Open index.html in your browser, or use a local server to serve the app.
